# Analyse sur la sous-nutrition dans le monde (FAO)

## 🎯 Mission
Mission réalisée pour la Food and Agriculture Organization of the United Nations (FAO). L'objectif était de réaliser une étude de grande ampleur sur l'alimentation mondiale et la sous-nutrition, en se basant sur des données historiques (2013-2017).

## 🛠 Tech Stack
- **Langage :** Python
- **Librairies :** Pandas, Matplotlib

## 🚀 Réalisations
- **Manipulation de données :** Importation, nettoyage et préparation de multiples jeux de données complexes.
- **Jointures complexes :** Réconciliation des différentes bases de données (population, disponibilité alimentaire, sous-nutrition) via Pandas.
- **Analyse exploratoire :** Extraction d'indicateurs clés sur la sécurité alimentaire mondiale et identification des tendances historiques.
- **Visualisation :** Création de graphiques pertinents avec Matplotlib pour illustrer les constats métiers.

## ✅ Compétences validées
- Justification des choix d'analyse auprès d'experts métiers.
- Maîtrise des manipulations techniques (jointures, agrégations) en Python.
